# 0004: Single-Container `debian:bookworm` Cross-Compilation Release Pipeline

All CI checks and multi-platform release builds (`x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu`, `x86_64-pc-windows-msvc`, and `aarch64-pc-windows-msvc`) run inside a `debian:bookworm` container on a Linux x86_64 runner (`vars.RUNNER_LABELS` defaulting to `[self-hosted, Linux, X64, git-oxide]` with `ubuntu-latest` fallback) rather than spinning up separate Windows or ARM64 runner VMs. Linux `arm64` binaries cross-link against Debian Bookworm multiarch libraries (`glibc 2.36` baseline for compatibility across Debian 12/13 and Ubuntu 22.04/24.04), Linux `.deb` and `.rpm` packages are built directly via `cargo-deb` and `cargo-generate-rpm`, and Windows `x64`/`arm64` static-CRT executables (`+crt-static`) are cross-compiled with `cargo-xwin` (`clang-cl` + MSVC SDK) and packaged into both standalone `.zip` archives and native Windows Installer `.msi` packages compiled on Linux via `wixl` (`packaging/windows/git-oxide.wxs`). This delivers full Linux and Windows installer/uninstaller and portable archive coverage from a single deterministic container where a draft GitHub Release is verified against `Cargo.toml` and `CHANGELOG.md` and published atomically with `SHA256SUMS` only after all targets succeed.
